# TASK-20260806-178 OPS-01 Completion Report

## Verdict: **Pass** (durable in-repo fix; Kurt Windows verify)

Blank persistent `python.exe` consoles at ALLSTART / Hermes start are caused by
Hermes spawning MCP stdio children with console-subsystem `python.exe` while the
gateway itself is Hidden. Fix: rewrite MCP `command:` to sibling `pythonw.exe`
on every `start-hermes.ps1` (and via a standalone patch script). MCP servers are
**not** killed or disabled.

Cloud agent cannot run Windows ALLSTART here — rewrite rules unit-tested; live
desktop verify steps for Kurt below.

```text

```

Kurt’s “a couple” blank windows matches 1–N stdio Python MCP entries (at least
`house_victoria`; any other `command: …python.exe` is rewritten too).
