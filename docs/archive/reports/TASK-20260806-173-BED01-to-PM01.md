## Design choice

**`CreateAsync` → `GetAsync(id)`** (kept `IVictoriaTaskStore.CreateAsync` returning `long`).

Reasons:
- No interface break for stubs/DI/tests
- Same authoritative `VictoriaTask` shape as `task_get` (`Data: VictoriaTask`)
- Store remains the single owner of defaults (`DefaultTaskStatus` / `DefaultTaskPriority`)

Rejected for this ticket: changing `CreateAsync` to return `VictoriaTask` (cleaner one-round-trip, but wider API churn; not needed for C).
