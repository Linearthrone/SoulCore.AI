# TASK-175 · BED-01 → PM-01 · Proactive chat sounds human

## Verdict: **Pass**

SoulLoop no longer dumps Inner-focus / want scaffold phrases into companion `chat.done`. Proactive pushes use a curated Victoria SMS phrase bank; unknown/scaffold-leaking text skips the push.

## Solution chosen: **A — Natural proactive only**

Kept `ProactiveChatEnabled=true` (code default + Example). Chat composition no longer interpolates `ExtractPhrase(want)`.

| Surface | Behavior after fix |
| --- | --- |
| Proactive `chat.done` | Category → natural SMS (1–2 short sentences) |
| `loop.want` / Inner-focus | Unchanged — still technical `want[…]` scaffolding |
| Unknown category | Empty compose → **skip push** (silence > scaffolding) |

## Defaults

| Knob | Value after change |
| --- | --- |
| `SoulLoop:ProactiveChatEnabled` | **`true`** (unchanged code default) |
| `SoulLoop:ProactiveChatIntervalTicks` | **`5`** (unchanged; ~5 min at 60s ticks) |
| `appsettings.json` SoulLoop block | Still omits proactive knobs → inherits code defaults |

To silence proactive chat entirely without this fix: set `SoulLoop:ProactiveChatEnabled=false` or `ProactiveChatIntervalTicks=0`.

## Changes

1. **`CompanionOutboundMessenger.ComposeProactiveText`** — category phrase bank only; never wraps scaffold want text (`"This came back to me: {phrase}"` removed).
2. **`ContainsScaffoldLeak`** — defense-in-depth detector for `want[`, `holding N recent beat(s)`, `weave it into presence`, emotion dumps, and known scaffold idioms.
3. **`SoulLoopScaffold.MaybePushProactiveChatAsync`** — skip when compose returns empty or leak detector trips.
4. **Tests** — recall want with `(holding 3 recent beats)` must not appear in composed chat; all categories audited; unknown category → empty.
