## Root cause (two issues)

1. **MCP HTTP not running (or not reachable) on shadow** — Tailscale L3 works; port **8080 closed/filtered** from main.
2. **Hostname mismatch in SoulCore defaults** — `appsettings.json` uses `http://housevictoria:8080` but Tailscale MagicDNS registers **`house-victoria`** (Windows host `House-Victoria`).

LLMOD quarry default `SERVER_HOST=localhost` in `MCPServer/.env.example` — even if MCP were started on shadow without changing host, remote main could not connect.
