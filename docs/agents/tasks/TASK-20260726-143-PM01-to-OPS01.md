## Solution

Restore the Hermes gateway from LLMOD (`C:\Users\kurtw\LLMOD\LLMOD-max-master`) to a runnable state on this machine:

### 1. Locate + restore the gateway

- Find the Hermes Python service (likely under `LLMOD/.../hermes/` or similar — document exact path).

- Confirm config `~/.hermes/config.yaml` (or equivalent) points at MCP servers.
- Start the gateway on `:8642`.

### 2. Wire MCP servers

Per the proposal inventory:

| MCP server | Tools | Notes |

- Confirm the gateway speaks OpenAI-compatible `/v1/chat/completions` with `tools` + `tool_choice` (the SoulCore client in BED-127 depends on this).

### 4. Process management

- Provide a start script (e.g. `SoulCore/scripts/start-hermes.ps1`) mirroring `start-soulcore.ps1` style: preflight, pid file, log path.
- Document how to stop / restart.
