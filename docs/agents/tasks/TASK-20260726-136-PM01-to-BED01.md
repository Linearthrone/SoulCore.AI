# TASK-136: Browser control tools

## Problem

LLMOD had `browser_bridge_health/capture_tab/click/type/key/scroll`. SoulCore has none. Restore browser tab control as LLM-callable tools. Read-only capture is always allowed; click/type gated by the same `AllowComputerControl` session opt-in as desktop (BED-135).

## Do not

- Do not implement desktop tools (BED-135) or MT4 (BED-138).
- Do not enable control without the session opt-in gate.
- Do not hardcode a specific browser — prefer a pluggable bridge; Hermes `browser_bridge` MCP when available (optional per TT-159).

## PM override (TT-159 Avenue C)

Native or honest stub Pass is acceptable without OPS-143 MCP. Document backend matrix in the report.

## Solution

`ITool` implementations wrapping a browser bridge backend (Hermes MCP preferred when present; native C# / CDP stub optional — document).

### Tools

```json
{ "name": "browser_health", "description": "Check browser bridge status.", "parameters":{ "type":"object","properties":{} } }
{ "name": "browser_capture_tab", "description": "Capture the current browser tab (screenshot + DOM).", "parameters":{ "type":"object","properties":{ "tab":{"type":"integer","default":0} } } }
{ "name": "browser_click", "description": "Click in the browser tab at coordinates.", "parameters":{ "type":"object","properties":{ "x":{"type":"integer"},"y":{"type":"integer"} }, "required":["x","y"] } }
{ "name": "browser_type", "description": "Type into the browser tab.", "parameters":{ "type":"object","properties":{ "text":{"type":"string"} }, "required":["text"] } }
{ "name": "browser_key", "description": "Press a key in the browser tab.", "parameters":{ "type":"object","properties":{ "key":{"type":"string"} }, "required":["key"] } }
```

Reuse `AllowComputerControl` for write tools; capture/health readable when capture allowed (mirror BED-135 patterns).

## Acceptance criteria

1. Tools registered; gate closed refuses click/type/key.
2. Capture/health path documented; works or honest Success:false with reason.
3. Unit tests for gates.
4. Report with platform/backend matrix.
