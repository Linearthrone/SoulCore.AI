# TASK-178: No leftover blank Python consoles on stack start

## Problem

On Windows ALLSTART / Hermes bring-up, **a couple of blank `python.exe` console windows** appear and **stay open** on the desktop. Kurt does not want them.

## Root cause (most likely)

`SoulCore/scripts/start-hermes.ps1` starts `hermes.exe gateway` with `-WindowStyle Hidden` — that part is fine. Hermes then spawns **MCP stdio children** from `%LOCALAPPDATA%\hermes\config.yaml` (`mcp_servers.house_victoria`, `house_victoria_data`, `computer_use`), typically:

```text
command: …\MCPServer\.venv\Scripts\python.exe
args: [-m, house_victoria_mcp]   # or computer_use / data
```

Those children are **console subsystem** `python.exe`. They allocate visible consoles, stay blank (blocked on stdio), and never close until Hermes stops. Count “a couple” matches 2–3 MCP servers.

Confirm with Task Manager: blank windows’ PIDs should be children of Hermes / listening under MCP, not SoulCore.Host.

## Solution (OPS owns)

Do **all** that apply; prefer durable fix over “minimize and hope”:

1. **Inventory:** After `.\ALLSTART.ps1` (or start-hermes), list visible python consoles + command lines + parent PID. Paste in report.
2. **Hermes MCP launch hide (primary):**
   - Prefer `pythonw.exe` (same venv `Scripts\`) as the MCP `command` instead of `python.exe`, **or**
   - Ensure Hermes/MCP spawn uses Win32 `CREATE_NO_WINDOW` / existing `windows_hide_flags()` for MCP children, **or**
   - Point each MCP `command` at a **hidden launcher** checked into SoulCore (e.g. `SoulCore/scripts/run-mcp-hidden.cmd` / `.ps1` / small helper) that starts the real module with no window and correct cwd/env.
3. **Persist config:** Update LLMOD `Tools\setup-hermes-integration.ps1` (quarry) **and/or** document a one-shot patch of `%LOCALAPPDATA%\hermes\config.yaml` so re-setup doesn’t regress. If SoulCore can safely rewrite MCP commands on `start-hermes.ps1` preflight (python → pythonw when sibling exists), do that with a clear log line.
4. **Do not** leave ALLSTART showing interactive PowerShell windows for Host/Hermes if avoidable (Host/Hermes scripts already use Hidden where possible — verify ALLSTART child windows too).
5. **ComfyUI / other:** If any blank python is Comfy (`:8188`) or unrelated, say so and hide that start path too — or note “status-only, not started by ALLSTART”.
