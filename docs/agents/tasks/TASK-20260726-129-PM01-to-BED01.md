# TASK-129: Model switch to `qwen2.5:14b` + tool-calling verification

## Context

User chose `qwen2.5:14b` for the agent tool-loop (very good tool-calling, fits 16 GB card). `gemma4:latest` is the current chat model but is **not confirmed** to support tool-calling reliably (gemma family not on Ollama's tool-calling list). The model is being pulled now.

**PM has already applied the config change** to `appsettings.json` and `appsettings.Example.json` (`Inference.Model` → `qwen2.5:14b`). This ticket owns **verification** that the model works for tool-calling.

## Do not

- Do not change `IToolRegistry` (BED-125) or tool-loop clients (BED-126/127) — but you may stub a one-tool registry to verify tool-calling end-to-end against `/api/chat`.
- Do not implement production tools (BED-131+).
- Do not block on `gemma4` — it is replaced, not tested alongside.

## Solution

### Step 1 — Confirm config

Verify both files already say `qwen2.5:14b` (PM applied). If `appsettings.json` was reverted or `bin/Debug` stale, fix.

```json
"Inference": {
  "Model": "qwen2.5:14b",
  ...
}
```

### Step 2 — Confirm model is pulled

```powershell
ollama list   # look for qwen2.5:14b
ollama show qwen2.5:14b   # confirm tool-calling capability if listed
```

If not yet pulled, wait (user is pulling). Do not pull yourself unless user says so.

### Step 3 — Tool-calling smoke

With BED-125 landed, write a minimal smoke (or unit test) that:
1. Builds a 1-tool `IToolRegistry` (e.g. `echo` or a stub `recall_memory`).
2. Calls `/api/chat` with `tools=[...]` and a user prompt that should trigger the tool (e.g. "use the echo tool to repeat 'hello'").
3. Asserts the model emits `tool_calls[0].function.name == "echo"` with arguments.
4. (Optional) feed the tool result back and confirm the model uses it in the final reply.

This can be a console smoke or an xUnit test marked `Category=ToolCalling` (skippable if model not present).

### Step 4 — Boot Host

Recycle `start-soulcore.ps1`. Confirm `/health` reports `inference.model=qwen2.5:14b` and a chat round-trip succeeds.
