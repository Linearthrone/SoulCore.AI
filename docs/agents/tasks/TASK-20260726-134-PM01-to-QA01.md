# TASK-134: Phase B exit gate — agency over memory + body

## Context

Phase B (core tools) is done when Victoria **by her own decision** (not user keyword) recalls a memory, waves, and walks. This is the gate that proves the model is driving her body and mind, not just reacting to your words.

## Test environment

- Host: `http://127.0.0.1:7700` · WS chat
- Ollama: `qwen2.5:14b` (BED-129)
- `IToolRegistry` (BED-125) + tool-loop (BED-126/128)
- `recall_memory` + `store_memory` (BED-131)
- Body tools: `speak`, `play_animation`, `move_to`, `look_at`, `set_emotion` (BED-132)
- `list_tools`, `system_info`, fs tools (BED-133)
- Unreal (for body): `ws://127.0.0.1:8888` with `BP_VictoriaCharacter` (BED-114/117 if available; else interim teleport)

## Acceptance criteria

1. **Self-discovery**: Chat "what tools do you have?" → model calls `list_tools` and reports a subset of tools in its reply (not a hardcoded list).
2. **Memory recall**: Seed a memory (e.g. "QUOKKA-134 wave test"); chat "what was the QUOKKA test about?" → model calls `recall_memory`, returns the seeded content in its reply.
3. **Memory store**: Chat "remember that I prefer the window seat" → model calls `store_memory`; verify a row lands in SQLite with `source='model'`.
4. **Body — wave**: Chat "wave goodbye to me" **without** using the word "wave" as a user command (e.g. "say farewell with your hand") → model calls `play_animation` with `name=wave_goodbye` (or equivalent); verify `PlayAnimationAsync` called via UnrealBridge (log or UE side).
5. **Body — walk**: Chat "go to the window" → model calls `move_to` with coordinates; verify `LocoAsync`/`MoveToAsync` dispatched. If BED-117 landed, expect path-follow; else interim teleport is acceptable (note in report).
6. **No keyword double-trigger**: when model calls `play_animation`, the keyword `DetectAnimationIntent` does not also fire (per BED-128 strategy).
7. **Iteration cap**: no chat exceeds `MaxToolIterations`; verify with one prompt that would trigger many calls.
8. **Regression**: E1 (speak) still works; `/health` clean; no exceptions in host log over a 5-message smoke.
9. Evidence in report: prompts, raw `tool_calls` JSON for each tool, host log excerpts, SQLite row for `store_memory`, Pass/Fail. File ISSUE on any failure.
