# PROP-22 mockups v2 (style lock candidate)

Operator feedback on v1: boards 2–4 glass language is the target; boards 5–6 felt gameish. Layout locks below.

## Layout locks (non-negotiable)

- **Radial status:** the three-quarter ring **protrudes outside** the glass slab (upper-left), as a separate owned popup — never clipped inside the window.
- **VM drawer:** when open, the drawer **protrudes from** the left or right edge of the main window as a separate owned popup. Sized so the **full guest display fits without scrollbars** (scale-to-fit the VM surface).

## Style lock (from boards 2 / 3 / most of 4)

- Near-black cool-tinted glass, soft depth
- Thin dull cool-white neon rim only
- Muted cool accents; no magenta / purple game HUD
- No brushed metal armor, no carbon plates, no RPG meters
- Quiet frosted panels; Inter / sentence case
