### 4. `KayleighPlayerCharacter` design (hard-rule compliant)

- Parent: `ACharacter` (Engine). **Does not reparent `BP_MHC_Kayleigh`**
  (MHC-regen safe — hard rule 4).
- Mesh: loads `/Game/MetaHumans/MHC_Kayleigh/Body/SKM_MHC_Natasha_BodyMesh`
  (depot-confirmed asset) in the constructor via `ConstructorHelpers::
  FObjectFinder`. Missing-asset is a warning, not fatal — pawn stays grounded.
- Capsule: radius 34, half-height 96 (mirror Victoria Phase 1).
- Camera: `CameraBoom` (arm 0, eye Z +64, `bUsePawnControlRotation`) +
  `FollowCamera` (eye-level). No free-fly.
- Movement: `MaxWalkSpeed=450`, crouched 200, `bOrientRotationToMovement=true`,
  `MOVE_Walking` (gravity on, no fly).
- Tag: `KayleighPlayer` (so the bridge/locator finds the player; never
  `VictoriaAvatar`).
- Post-process AnimBP `ABP_Body_PostProcess` + locomotion AnimBP (prefer
  `ABP_Kayleigh_Locomotion`, fallback `ABP_Victoria_Locomotion`) — best-effort.

### 5. `HouseGameMode` design (BOB-class guard)
