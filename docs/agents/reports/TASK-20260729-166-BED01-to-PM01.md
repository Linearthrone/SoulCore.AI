## Root cause

Ollama OpenAI-compat expects OpenAI wire shape: `arguments` is a JSON
**string**. Host keeps object-form args in-memory (native `/api/chat` +
`ChatMessage` contract). When ForceTool iteration 0 posted history with
object-form `arguments` to `/v1`, Ollama returned:

```text
cannot unmarshal object into Go struct field
.messages.tool_calls.function.arguments of type string
```

Exclusive tools[] worked; the request never reached the model → no dispatch.
