# TASK-176: House.ChatDesktop presence UI rewrite

## Product ask (Kurt)

Rewrite `House/House.ChatDesktop` (Avalonia **11.3.x only**) so Presence feels like **SMS/MMS**, with a clear Victoria state HUD, services status, and a **future-tech frosted metal** look. Kill confusing panels and filler status text.

## Visual direction (binding)

- **Look:** polished blueish-purple metal panels; **carbon-fiber** accents; visible **security-bit screw heads** so chrome feels bolted onto the desktop
- **Glass:** windows/panels blend into whatever is behind them (frosted / acrylic-like translucency — Avalonia-realistic, not fake neon glow)
- **Avoid:** bright neons, purple-on-white AI defaults, harsh glow spam
- **Chrome controls on every major panel:** **Pop out** (detach to own window) + **Always on top** lock toggle
- Fonts: expressive where it helps; keep Avalonia 11.3.x compatible

## Presence (main) layout — one composition

### 1. SMS/MMS chat (primary)

- Message **bubbles** (user vs Victoria), timestamps, clear thread
- Send/receive **images** (MMS): paste/attach outbound; render inbound image parts from Host/companion frames when present (wire to existing media/`chat.done` capabilities; stub gracefully if Host lacks image payload yet — document gap)
- **Voice/video controls live here** (not Settings): hold-to-talk / mic affordance; video placeholder OK if WebRTC still deferred
- **No “Working…” / busy filler** in the transcript or composer. Subtle typing indicator or nothing — never a fake “Working…” bubble
- System/SoulLoop scaffold must **not** appear as chat (BED-175 cleans Host; FED must not surface Inner-focus dumps as messages)

### 2. Victoria state HUD (replaces Inner focus + Emotion strip)

Remove **Inner focus** as a concept Kurt must decode. Replace with:

| Element | Behavior |
| --- | --- |
| **Overall mood** | Clear label + color from emotion snapshot |
| **Low / High gauges** | Simple valence/arousal (or calm↔activated) gauges — readable at a glance |
| **Current activity** | Plain language: what she’s doing now — **not** “holding 3 recent beats” |
| **Engaged vs sleeping** | Dedicated status: Engaged in activity / Idle / Sleeping |

### 3. Services panel

Clear status of **all servers**: Host, Ollama, Hermes, CUA, Unreal, ComfyUI, ChatDesktop. Unreal is just a service row (no separate Unreal settings tab).
