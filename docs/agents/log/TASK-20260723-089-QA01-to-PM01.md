## Note on previous false failures (QA-084/086)

The earlier E3/E1 "inference timeout" failures were a test-harness artifact: the QA-086
robust scripts canceled in-flight `ReceiveAsync` during the inference window, which
aborted the WS connection from the client side and caused the Host to cancel the Ollama
HTTP request (`TaskCanceledException`). The fixed "send -> wait -> drain" pattern
(used here and in QA-087) avoids this by not calling `ReceiveAsync` until after inference
completes.
