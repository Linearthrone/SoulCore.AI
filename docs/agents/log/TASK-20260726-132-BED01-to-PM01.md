## 3. Schemas

### `speak`
```json
{ "type":"object", "properties":{ "text":{"type":"string","description":"Text to speak aloud (TTS). Prefer for mid-loop interjections; final reply is auto-spoken."} }, "required":["text"] }
```
Wraps `SpeakAsync(text)`. **Interaction with auto-speak:** chat handler already TTS-speaks the final reply; this tool is for **additional mid-loop utterances** only.

### `play_animation`
```json
{ "type":"object", "properties":{ "name":{"type":"string","description":"Animation name, e.g. wave, nod, wave_goodbye, …"} }, "required":["name"] }
```
Wraps `PlayAnimationAsync(resolvedName)` after `AnimationNameMap.Resolve`.

### `move_to`
```json
{ "type":"object", "properties":{ "x":{"type":"number"}, "y":{"type":"number"}, "z":{"type":"number"} }, "required":["x","y"] }
```
Wraps `LocoAsync({ forward=x, right=y, up=z, mode="relative_offset_interim" })`. `z` optional (default 0).

### `look_at`
```json
{ "type":"object", "properties":{ "target":{"type":"string","description":"player | x,y,z"} }, "required":["target"] }
```
Wraps `LookAsync(payload)`. UE mapper still always emits `look_at_player`; point targets are accepted and forwarded for schema stability.

### `set_emotion`
```json
{ "type":"object", "properties":{ "emotion":{"type":"string","description":"neutral | happy | sad | angry | curious"} }, "required":["emotion"] }
```
Wraps `SetEmotionAsync` with VAD + label presets:

| emotion | valence | arousal | dominance |
| --- | --- | --- | --- |
| neutral | 0.0 | 0.25 | 0.0 |
| happy | 0.7 | 0.55 | 0.3 |
| sad | -0.6 | 0.25 | -0.2 |
| angry | -0.55 | 0.8 | 0.55 |
| curious | 0.25 | 0.6 | 0.2 |
