## Blocker cleared before formal run (P0)

First WS `chat.send` against a freshly started Host returned **0 frames**. Host log:

```
fail: Microsoft.AspNetCore.Server.Kestrel[13]
      System.InvalidOperationException: A circular dependency was detected for the service of type
      'System.Collections.Generic.IEnumerable<SoulCore.Inference.ITool>'.
      ChatWebSocketHandler -> IToolRegistry(ToolRegistry) -> IEnumerable<ITool>
        -> ITool(ListToolsTool) -> IEnumerable<ITool>
```

**Root cause:** `AddSingleton<ITool, ListToolsTool>()` lets MS.DI pick the test ctor `ListToolsTool(IEnumerable<ITool>)` over `ListToolsTool(IServiceProvider)`.

**QA unblock (minimal):** factory registration in `SoulCore.Host/Program.cs`:

```csharp
builder.Services.AddSingleton<ITool>(sp => new ListToolsTool(sp));
```

**Issue filed:** `docs/agents/issues/ISSUE-20260727-001-listtoolstool-di-ctor-ambiguity.md` (P0). DEV should keep the factory (or `[ActivatorUtilitiesConstructor]`) and add a DI resolve regression test.
