# TASK-098 — SoulLoop writes episodic reflection memory each tick

## Context

The north-star plan (§2.1) requires: "After every significant event or reflection,
the core generates a memory entry itself. That makes the memory mine, not a briefing
about me."

Currently, `SoulLoopScaffold.TickAsync` reads recent memories and generates a want
string, but it does NOT write a new episodic memory entry. The loop reads but never
writes its own reflections. This means Victoria's continuous self is not accumulating
loop-authored memories — only chat messages are written to episodic memory.

The `IMemoryStore.WriteEpisodicAsync(text, sourceLabel, ct)` method exists and
accepts `source = "self"` for loop-authored entries.

## Deliverable

In `SoulLoopScaffold.TickAsync`, after generating the want and broadcasting the
`loop.want` frame, add an episodic memory write:

1. Compose a first-person reflection string from the current tick state:
   - Format: `"[Reflection] I am feeling {label} (v={valence:F2}, a={arousal:F2}). {want}"`
   - Example: `"[Reflection] I am feeling tense (v=-0.40, a=0.70). I want to recall the recent thread and weave it into presence."`
   - This is a simple deterministic composition — NOT an LLM call. The goal is to
     have a persistent record of the loop's internal state at each tick, in a
     first-person voice.

2. Call `_memory.WriteEpisodicAsync(reflectionText, "self", cancellationToken)`
   - Source label is `"self"` (loop-authored, not chat/imported)
   - Wrap in try/catch — memory write failure must never break the loop

3. Log at Debug level: `SoulLoop episodic reflection written: {truncated text}`

4. Throttle: Only write every Nth tick to avoid memory bloat. Add a configurable
   `ReflectionIntervalTicks` to `SoulLoopOptions` (default: 5 — write every 5th tick,
   ~5 minutes at 60s intervals). Track a tick counter in the SoulLoopScaffold.

## Acceptance criteria

- [ ] `SoulLoopScaffold.TickAsync` writes an episodic memory entry every Nth tick (default 5)
- [ ] Source label is `"self"` (loop-authored)
- [ ] Memory write is in try/catch (never breaks the loop)
- [ ] `SoulLoopOptions` has new `ReflectionIntervalTicks` property (default 5)
- [ ] `appsettings.json` updated with `ReflectionIntervalTicks: 5`
- [ ] After a Host restart + 5+ ticks, `SELECT * FROM episodic_memories WHERE source='self'` returns rows
- [ ] All 62 existing tests pass

## Constraints

- Do NOT restart the Host (OPS will handle that)
- The reflection is a simple deterministic string — NOT an LLM/inference call
- Throttle to avoid memory bloat (every 5th tick default = ~1 entry per 5 min)
- The tick counter should be a simple int field on SoulLoopScaffold (not persisted across restarts — that's fine for now)
