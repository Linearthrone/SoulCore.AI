# TASK-044 · FED-01 → PM-01 · CorrectSlider NRE launch crash fixed

## Summary

`House.ChatDesktop` no longer crashes during `InitializeComponent`. `CorrectSlider_ValueChanged` now null-guards **all** Correct* sliders and value TextBlocks before reading/writing them.

## Fix approach

**Root cause:** XAML attaches `ValueChanged` as each Correct* slider is constructed. The first slider’s event ran while later controls (`CorrectDominanceValue`, `CorrectFocusSlider`, etc.) were still null. The old guard only checked `CorrectValenceValue`, then unconditionally touched the rest → NRE at ~L152.

**Change:** In `House/House.ChatDesktop/MainWindow.xaml.cs` `CorrectSlider_ValueChanged`, return early unless every `Correct*Slider` and `Correct*Value` is non-null. After full init, behavior is unchanged (label sync on slider move).
