# TASK-112 Report: Start-script inference/embed preflight

## Summary

Hardened `SoulCore/scripts/start-soulcore.ps1` with an advisory Ollama + embed-model
preflight (TASK-112). The preflight runs after `.env` load and before the Host starts.
It **never hard-fails** Host start by default — an offline Host can still serve
health/WS stubs. Warnings only; no secrets/API keys are printed.

Only `SoulCore/scripts/start-soulcore.ps1` was modified (plus this report).

## Changes

- **New params**
  - `-PullEmbedModel` (switch, opt-in): run `ollama pull <embed-model>` when the model is missing.
  - `-OllamaUrl` (string, default `http://127.0.0.1:11434`): base URL for the probe.
  - `-SkipPreflight` (switch): bypass the preflight entirely.
- **New function `Invoke-InferencePreflight`**
  - Resolves the embedding model from env `SOULCORE_EMBED_MODEL` (loaded from
    `SoulCore/.env` if present), defaulting to **`nomic-embed-text`**.
  - Probes `<OllamaUrl>/api/tags` with a 5s timeout.
  - **Ollama unreachable** → `WARNING` (Host still starts; embeddings/recall degraded) + remedy to start Ollama.
  - **Model missing** → `WARNING` + remedy `ollama pull <model>`. With `-PullEmbedModel` it runs the pull (guarded, non-fatal on failure).
  - **Model present** → confirmation line; no behavior change.
  - Tag matching accepts `<model>`, `<model>:latest`, and `<model>:*`.
- **Header comment** updated (`.DESCRIPTION`) documenting the preflight, defaults, and opt-in pull.
- Existing start behavior (build, `.env` load, loopback bind, PID/log/health) is unchanged; preflight is inserted just before "Starting SoulCore.Host …".

## How to use `-PullEmbedModel`

```powershell
# Normal start — warns if Ollama down or embed model missing, but still starts Host:
.\SoulCore\scripts\start-soulcore.ps1

# Auto-pull the embedding model when it is missing (opt-in):
.\SoulCore\scripts\start-soulcore.ps1 -PullEmbedModel

# Point at a non-default Ollama, or skip the preflight:
.\SoulCore\scripts\start-soulcore.ps1 -OllamaUrl http://127.0.0.1:11434 -PullEmbedModel
.\SoulCore\scripts\start-soulcore.ps1 -SkipPreflight
```

`-PullEmbedModel` only pulls when the model is absent from `/api/tags`. When Ollama is
unreachable, no pull is attempted (nothing to pull against) — the unreachable WARNING is shown.
Override the model name via env `SOULCORE_EMBED_MODEL` (in `SoulCore/.env` or the process env).

## Notes / limitations

- The preflight is skipped on the early-exit path where the Host is *already* listening
  (`start-soulcore.ps1` returns before build/start in that case), which matches "start" semantics.
- `-PullEmbedModel` depends on the `ollama` CLI being on PATH; a missing CLI is caught and reported as a WARNING (non-fatal), so Host start is never blocked.
