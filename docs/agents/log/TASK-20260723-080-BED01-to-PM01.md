## Implementation Details

### F1: CharterService
- Implements all three `ICharter` methods: `GetAnchorsAsync`, `GetAnchorsByKindAsync`, `SeedAsync`
- Opens its own `SqliteConnection` (does NOT use `SqliteMemoryStore`) with `EnsureSchema()` that creates the `charter_anchors` table matching the canonical DDL from `001_schema.sql`
- Validates `kind` (identity/safety/value/boundary/ritual) and `source` (seed/imported/calibration/system) against the schema CHECK constraints
- `SeedAsync` uses a transaction — rolls back on any validation failure
- Supports `lockedOnly` filter on `GetAnchorsByKindAsync`
- Returns anchors ordered by `priority ASC, id ASC` (lower = higher priority, matching schema)
- Implements `IDisposable` + `IAsyncDisposable`
- Tests use temp DB files in `%TEMP%` with GUID-based names, cleaned up in `Dispose`

### F2: DriftWatcher
- Pure in-memory, no external dependencies
- `RecordDrift(DriftReport)` adds to unacked list (thread-safe with lock)
- `GetStatus(now)` returns `DriftStatus` with `LastDriftReport`, `UnackedReports` count, and `SloExceeded` boolean
- `SloExceeded` is computed by comparing the oldest unacked report's `ObservedAt` against the SLO window — accepts an injectable `now` for deterministic testing
- `AcknowledgeAll()` and `AcknowledgeOldest()` for FIFO acknowledgement
- Report-only — does NOT block acts (per task spec; future gate)

### F3: SpendMeter
- Pure in-memory, no external dependencies
- `RecordUsage(provider, tokensIn, tokensOut)` accumulates token counts and computes cost
- Cost = `(tokensIn / 1000) * inputRate + (tokensOut / 1000) * outputRate`
- `GetSummary()` returns `SpendSummary` with totals, estimated cost, monthly cap, and `CapExceeded` boolean
- `CapExceeded` flips true when `EstimatedCost >= MonthlyCap` (configurable, default $30)
- `Reset()` clears counters and returns the pre-reset summary (for billing cycle rollover)
- Thread-safe with lock

### F4: SafetyOptions
- Defined in `SoulCore.Config` following the existing pattern (`SectionName` const, non-secret knobs)
- Properties: `DriftSloMinutes` (15), `MonthlyCapUsd` ($30), `InputTokenRatePer1K` ($0), `OutputTokenRatePer1K` ($0)
- NOT bound in `Program.cs` or `appsettings.json` — available for future wiring
