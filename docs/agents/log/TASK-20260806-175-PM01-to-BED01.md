# TASK-175: Proactive chat must sound human — not Inner-focus scaffolding

## Problem

With SoulLoop enabled, every ~5 minutes Kurt gets an unsolicited chat line like:

> This came back to me: recall the recent thread and weave it into presence (holding 3 recent beats)

That string is the **internal want proposal** (`SoulLoopWantProposal` CategoryRecall), wrapped by `CompanionOutboundMessenger.ComposeProactiveText("recall", …)`. It is not a real companion message. Inner focus / want wire may keep technical phrases; **chat must not**.

## Root cause

| Piece | Path |
| --- | --- |
| Want text | `SoulCore.Core/SoulLoopWantProposal.cs` — `"recall the recent thread and weave it into presence ({episodeCue})"` |
| Throttle | `SoulLoopOptions.ProactiveChatIntervalTicks=5` × `TickIntervalSeconds=60` ≈ 5 min |
| Push | `SoulLoopScaffold.MaybePushProactiveChatAsync` → `ComposeProactiveText` |
| Wrapper | `CompanionOutboundMessenger.cs` — `"recall" => $"This came back to me: {phrase}"` where phrase still contains the scaffold |

## Solution (pick A or B; document)

### Preferred A — Natural proactive only

1. Proactive chat text must be **user-facing natural language**, never containing:
   - `want[…]`
   - `holding N recent beats`
   - `weave it into presence` / other scaffold idioms
   - raw emotion dumps (`emotion=… v=…`)
2. Either:
   - Short LLM-authored check-in from want category + recent episodic (budgeted, SpendMeter-aware), **or**
   - A small curated phrase bank per category that sounds like Victoria SMS (no scaffold verbs)
3. Keep `loop.want` able to show Mode/Feeling/Focus for ops until FED redesign.
4. If no good natural line can be produced, **skip the push** (silence > scaffolding).

### Acceptable B — Disable proactive chat by default

Set `ProactiveChatEnabled=false` in appsettings + code default; document how to re-enable after A lands. Still strip scaffold if someone enables it.

## Also

- Audit all `ComposeProactiveText` categories for the same leak.
- Unit tests: recall want with `(holding 3 recent beats)` must **not** appear in composed chat text; or proactive returns empty/skip.
- Do not change tick interval unless needed; fix content, not just frequency.

| 2 | If proactive fires, text reads as companion SMS (1–2 short sentences) |
| 3 | Tests cover ComposeProactiveText / push skip |
| 4 | Report notes default (`ProactiveChatEnabled`) after change |
