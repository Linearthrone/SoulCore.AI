# TASK-136: Browser control tools

## Problem

LLMOD had `browser_bridge_health/capture_tab/click/type/key/scroll`. SoulCore has none. Restore browser tab control as LLM-callable tools. Read-only capture is always allowed; click/type gated by the same `AllowComputerControl` session opt-in as desktop (BED-135).

## Do not

- Do not implement desktop tools (BED-135) or MT4 (BED-138).
- Do not enable control without the session opt-in gate.
- Do not hardcode a specific browser — route through Hermes `browser_bridge` MCP (restored in OPS-143) when available.

## Solution

`ITool` implementations wrapping a browser bridge backend (Hermes MCP preferred; native C# fallback optional — document).

### Tools

```json
{ "name": "browser_health", "description": "Check browser bridge status.", "parameters":{ "type":"object","properties":{} } }
{ "name": "browser_capture_tab", "description": "Capture the current browser tab (screenshot + DOM).", "parameters":{ "type":"object","properties":{ "tab":{"type":"integer","default":0} } } }
{ "name": "browser_click", "description": "Click in the browser tab at coordinates.", "parameters":{ "type":"object","properties":{ "x":{"type":"integer"},"y":{"type":"integer"} }, "required":["x","y"] } }
{ "name": "browser_type", "description": "Type into the browser tab.", "parameters":{ "type":"object","properties":{ "text":{"type":"string"} }, "required":["text"] } }
{ "name": "browser_key", "description": "Press a key in the browser tab.", "parameters":{ "type":"object","properties":{ "key":{"type":"string"} }, "required":["key"] } }
{ "name": "browser_scroll", "description": "Scroll the browser tab.", "parameters":{ "type":"object","properties":{ "dx":{"type":"integer","default":0},"dy":{"type":"integer","default":0} } } }
```

### Gate

| Action | Gate |
| --- | --- |
| `browser_health`, `browser_capture_tab` (read) | `Tools.AllowBrowserCapture=true` (default true) |
| `browser_click/type/key/scroll` (write) | `Tools.AllowComputerControl=false` by default (same session gate as desktop) |

### Config

Extend `ToolsOptions` from BED-135:
```json
"Tools": {
  "AllowBrowserCapture": true,
  "AllowComputerControl": false,
  "BrowserBackend": "hermes"
}
```

## Acceptance criteria

1. All six tools implement `ITool`, register, appear in registry.
2. Gate enforcement: with `AllowComputerControl=false`, `browser_click/type/key/scroll` refuse; `browser_health` + `browser_capture_tab` work when capture allowed.
3. `browser_capture_tab` returns screenshot path + optional DOM text the model can read.
4. Hermes path: routes through `IHermesClient`/MCP `browser_bridge` when `BrowserBackend=hermes` and OPS-143 done.
5. Unit tests: gate closed refuses control; gate open allows (mock backend).
6. Report: file paths, gate logic, backend choice, unit evidence.
