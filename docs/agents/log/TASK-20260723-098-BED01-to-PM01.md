## Approach

### 1. `SoulLoopOptions.ReflectionIntervalTicks` (new)

```csharp
/// <summary>
/// Write an episodic self-reflection memory every Nth tick (default 5, ~5 min at 60s ticks).
/// Set to 0 to disable loop-authored reflection writes entirely.
/// </summary>
public int ReflectionIntervalTicks { get; set; } = 5;
```

Default 5 = one reflection entry per ~5 minutes at the 60s tick interval. `0` disables
the write entirely (escape hatch).

### 2. `SoulLoopScaffold` tick counter + reflection write

Added a non-persisted `private int _tickCount;` field. After the `loop.want` broadcast
block (matching the task ordering: "after generating the want and broadcasting the
loop.want frame"), added:

```csharp
// Episodic self-reflection: write a first-person memory every Nth tick.
// Throttled to avoid memory bloat (default every 5th tick). Never breaks the loop.
var interval = _options.ReflectionIntervalTicks;
if (interval > 0)
{
    var tick = ++_tickCount;
    if (tick % interval == 0)
    {
        var reflection = string.Format(
            CultureInfo.InvariantCulture,
            "[Reflection] I am feeling {0} (v={1:F2}, a={2:F2}). {3}",
            label,
            fields.Valence,
            fields.Arousal,
            want);
        try
        {
            await _memory
                .WriteEpisodicAsync(reflection, "self", cancellationToken)
                .ConfigureAwait(false);
            _logger.LogDebug(
                "SoulLoop episodic reflection written: {Reflection}",
                reflection.Length > 80 ? reflection[..80] + "..." : reflection);
        }
        catch (Exception ex)
        {
            _logger.LogDebug(ex, "SoulLoop episodic reflection write failed (loop continues)");
        }
    }
}
```

Key design points:
- **Deterministic string, NOT an LLM call** — composed purely from the current tick's
  `label`, `fields.Valence`, `fields.Arousal`, and `want`. No inference.
- **Invariant culture formatting** — `string.Format` with `CultureInfo.InvariantCulture`
  and `:F2` produces stable output like `-0.40` / `0.70` regardless of system locale,
  matching the `EmotionInfluencePrompt` invariant-culture convention.
- **Throttle**: `++_tickCount % interval == 0` writes on ticks 5, 10, 15, ... (interval 5).
  `interval <= 0` skips the whole block (disable switch).
- **try/catch** wraps the memory write; failures log at Debug and the loop continues.
- **Source label `"self"`** — loop-authored, distinct from chat/imported entries.
- **Debug log** with truncated text (80 chars + `...`) to avoid noisy logs.

### 3. `appsettings.json` + `appsettings.Example.json`

Added `"ReflectionIntervalTicks": 5` to the SoulLoop section in both files. The example
file's `_note` was updated to document the `0 = disable` escape hatch.
