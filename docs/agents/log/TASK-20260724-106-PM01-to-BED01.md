# TASK-106: Ollama embeddings + semantic episodic recall

## Context

Chat context currently uses `RecallRecentAsync` (last N by time). Schema already has `episodic_embeddings_meta` + a **commented** sqlite-vec `vec0` plan. Native sqlite-vec on Windows is a separate packaging problem — for this wave, ship **real Ollama embeddings** + **in-process cosine top-K** stored as BLOBs. Keep `RecallRecentAsync` as fallback when embeddings are disabled or fail. Native `vec0` remains a follow-up.

## Acceptance criteria

### 1. Config
- Add to `InferenceOptions` (or new `EmbeddingOptions` under Inference/Memory — pick one place):
  - `EmbeddingsEnabled` (bool, default **true** when Inference.Enabled)
  - `EmbeddingModel` (string, default `nomic-embed-text`)
- Mirror in `appsettings.json` / Example under Inference:
  ```json
  "EmbeddingModel": "nomic-embed-text",
  "EmbeddingsEnabled": true
  ```

### 2. Embedding client
- New `IEmbeddingClient` + `OllamaEmbeddingClient` calling Ollama `POST /api/embeddings` `{ model, prompt }` → `embedding` float[].
- `NullEmbeddingClient` when disabled.
- Register in `Program.cs` like inference HttpClient (same BaseUrl/timeout family).

### 3. Memory store
- Extend `IMemoryStore`:
  - After `WriteEpisodicAsync`, optionally embed (caller may pass embedding, OR store accepts optional `IEmbeddingClient` — prefer **store stays pure** and Host/chat path embeds then calls new `WriteEpisodicEmbeddingAsync(episodicId, float[] vector, string model)` — OR return inserted id from WriteEpisodicAsync).
  - Simplest acceptable design:
    - Change `WriteEpisodicAsync` to return `long` row id (breaking but contained).
    - Add `Task StoreEmbeddingAsync(long episodicId, float[] vector, string model, ct)`.
    - Add `Task<IReadOnlyList<string>> RecallSimilarAsync(float[] queryVector, int limit, ct)` — load candidate embeddings for non-quarantined episodics (cap scan e.g. last 500), cosine similarity, return top `limit` content strings.
  - Persist vector as little-endian float32 blob in a new table `episodic_embedding_vectors (episodic_id PK, model, dims, vector BLOB, created_at)` **or** reuse `episodic_embeddings_meta` + add `vector BLOB` column via migration `002` if needed. Prefer migration `002` if altering schema; if table unused, add column via `CREATE TABLE IF NOT EXISTS` in ApplyMigrations.

### 4. Chat path
- In `HandleChatSendAsync`, when embeddings enabled:
  1. Embed user text via `IEmbeddingClient`.
  2. `RecallSimilarAsync(queryVec, 5)` for `[Memory]` section.
  3. On any failure → fall back to `RecallRecentAsync(5)` (Debug log).
- After successful chat episodic write, embed the episode text and `StoreEmbeddingAsync` (best-effort; never fail chat).

### 5. Tests
- Unit test cosine ranking helper (deterministic vectors).
- Build + Protocol.Tests pass (add focused tests; don't require live Ollama in CI — mock/null path).

### 6. Out of scope
- Loading native sqlite-vec / `CREATE VIRTUAL TABLE ... vec0`
- Backfilling embeddings for all historical rows (optional script later)
- Changing charter/identity section
