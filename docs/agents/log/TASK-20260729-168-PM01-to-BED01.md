# TASK-168: ForceTool text-only → soft-dispatch / forced retry nudge

## Problem

QA-142 Retest-4: `ForceToolName=workflow_execute` + exclusive `/v1`
`tool_choice` returns HTTP 200, but the model emits clarification prose with
**no** `tool_calls` → Host ends the loop → **no dispatch**. AC5/AC7 Pass;
**AC6 Fail**.

## Solution

On ForceTool rounds, text-only must **not** end the loop:

1. Soft-dispatch `workflow_execute` with `{id, all:true}` when a session
   workflow id is already known (prior create/get/execute tool results or
   tool_call args).
2. Otherwise inject one forced retry nudge (keep exclusive `tools[]` +
   `tool_choice`) so the model must emit the tool call.

Keep BED-165/166/162/164/167 intact.

2. ForceTool text-only without id → one retry nudge, force retained, then
   dispatch when model complies.
