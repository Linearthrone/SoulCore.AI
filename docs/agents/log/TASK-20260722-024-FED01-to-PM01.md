## Behavior

1. Connect → handshake `presence.status` drives Alive/Warm; `emotion.snapshot` fills emotion strip  
2. User Send → `chat.send` only (no LLM client in House)  
3. Host replies → one assistant bubble updated from `chat.delta` then finalized on `chat.done` (user vs assistant brushes from TASK-022)  
4. Host down → Unavailable chrome + system line; Refresh / health poll can reconnect  

Override (loopback only): `HOUSE_SOULCORE_HOST`, `HOUSE_SOULCORE_PORT`.

## How to demo

```powershell
# 1) Host already listening on :7700 (or start it)
dotnet run --project SoulCore\SoulCore.Host -c Release

# 2) Presence shell
dotnet run --project House\House.ChatDesktop -c Release
# or: .\House\House.ChatDesktop\bin\Release\net8.0-windows\House.ChatDesktop.exe
```

1. Confirm top chrome shows **WS connected** and Alive/Warm from handshake.  
2. Emotion strip shows label/valence/arousal from `emotion.snapshot` (e.g. `calm` / `0.0`).  
3. Type a message → Send. User bubble (You) then Victoria assistant bubble with Host stub reply, e.g. `[stub] SoulCore received: …`.  
4. Stop Host → UI reports WS down; Restart Host → Refresh reconnects.
