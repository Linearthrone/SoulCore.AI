# TASK-106 report (BED-01 → PM-01)

## Summary

Shipped real Ollama embeddings + in-process cosine top-K episodic recall for chat context. Native sqlite-vec `vec0` **not** implemented (deferred). `RecallRecentAsync` remains the graceful fallback whenever embeddings are disabled or fail.

## API surface

| Surface | Shape |
|--------|--------|
| `InferenceOptions` | `EmbeddingsEnabled` (bool, default `true`), `EmbeddingModel` (string, default `nomic-embed-text`) |
| `IEmbeddingClient` | `IsEnabled`, `Model`, `EmbedAsync(text)` → `float[]` |
| Impls | `OllamaEmbeddingClient` (`POST /api/embeddings` `{ model, prompt }` → `embedding`), `NullEmbeddingClient` |
| `IMemoryStore.WriteEpisodicAsync` | now returns `long` row id |
| `IMemoryStore.StoreEmbeddingAsync` | `(episodicId, float[] vector, string model)` — LE float32 BLOB upsert |
| `IMemoryStore.RecallSimilarAsync` | `(queryVector, limit)` — scan last ≤500 non-quarantined with matching dims, cosine top-K content |
| `VectorSimilarity` | `Cosine`, `RankByCosineTopK`, LE blob serialize/deserialize |
| Schema | Migration **002** → table `episodic_embedding_vectors (episodic_id PK, model, dims, vector BLOB, created_at)` |

### Chat path (`HandleChatSendAsync`)

1. If embeddings enabled → embed user text → `RecallSimilarAsync(..., 5)` for `[Memory]`.
2. On empty/fail/disabled → `RecallRecentAsync(5)` (Debug log).
3. After successful non-stub chat episodic write → best-effort embed episode + `StoreEmbeddingAsync` (never fails chat).

### DI (`Program.cs`)

Registers `OllamaEmbeddingClient` when `Inference.Enabled && EmbeddingsEnabled`; else `NullEmbeddingClient`. Same BaseUrl/timeout family as inference HttpClient. `/health` exposes `inference.embeddingsEnabled` + `embeddingModel`.
