# TASK-092 — play_animation keyword dispatch — DONE

## Summary

Added a keyword-based animation intent detector (`DetectAnimationIntent`) to
`ChatWebSocketHandler.HandleChatSendAsync`, following the exact pattern of
BED-088's loco dispatch. When the ORIGINAL user chat text contains an animation
keyword, the handler calls `_unreal.PlayAnimationAsync(animationName, ct)`,
which maps to the UE `play_animation` command frame via
`UeVerbWireMapper.MapPlayAnimation`. The block is wrapped in an independent
try/catch so an animation failure can never break the chat flow.

## Files changed

- `SoulCore/SoulCore.Host/Ws/ChatWebSocketHandler.cs`
  - Added `DetectAnimationIntent(string text)` private static method (multi-word
    phrases checked before single words).
  - Added an independent try/catch animation dispatch block immediately after
    the loco dispatch block in `HandleChatSendAsync`.

## Implementation details

### Animation dispatch block (after loco dispatch)

```csharp
// Animation intent dispatch — keyword detection on the ORIGINAL user text.
// Independent try/catch so animation runs even if loco/speak failed and never breaks chat.
try
{
    var animationName = DetectAnimationIntent(text);
    if (animationName is not null)
    {
        await _unreal.PlayAnimationAsync(animationName, cancellationToken).ConfigureAwait(false);
        _logger.LogInformation(
            "Unreal animation intent dispatched: anim={AnimationName} (from chat text)",
            animationName);
    }
}
catch (Exception ex)
{
    _logger.LogDebug(ex, "Unreal animation side-effect ignored");
}
```

### Keyword mapping (multi-word phrases first)

| User chat phrase / keyword                | UE animation name |
|-------------------------------------------|-------------------|
| "wave hello" / "wave goodbye" / "wave bye" | `wave`            |
| "wave"                                     | `wave`            |
| "shake head" / "shake your head"           | `shake_head`      |
| "nod" / "yes"                              | `nod`             |
| "no"                                       | `shake_head`      |
| "bow"                                      | `bow`             |
| "clap" / "applaud"                         | `clap`            |
| "dance"                                    | `dance`           |
| "laugh" / "giggle"                         | `laugh`           |
| "thumbs up" / "thumbs-up"                  | `thumbs_up`       |
| "point at" / "point"                       | `point`           |
| "jump"                                     | `jump`            |
| "sit down" / "sit"                         | `sit`             |
| "stand up" / "stand"                       | `stand`           |

Multi-word phrases ("wave goodbye", "shake head", "thumbs up", "sit down",
"stand up", "point at") are evaluated before the single-word triggers so the
more specific match wins, exactly as the loco detector checks "turn left"
before "left".

### Wire path

`_unreal.PlayAnimationAsync(animationName, ct)`
→ `UnrealVerbClientStub.SendVerbAsync(UnrealVerbTypes.PlayAnimation, new { name = animationName }, ct)`
→ `UeVerbWireMapper.MapPlayAnimation` reads `payload.name`
→ emits `{type:"command",payload:{name:"play_animation",args:{name:"<anim>"}}}`.
