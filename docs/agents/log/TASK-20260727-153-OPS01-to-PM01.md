### CLI gotchas (documented in runbook)

- `tailscale serve --bg 7700` fails if **443** already has a listener (`listener already exists for port 443`).
- Flag order / target form: use `tailscale serve --https=8443 --bg --yes 7700` (bare port). Forms like `http://127.0.0.1:7700` → `invalid argument format` on 1.98.9.
- Pre-existing config had **Funnel** on `/` → Ollama `:11434`. Adding a path temporarily cleared Funnel; cleanup restored **tailnet-only** serve for Ollama on `:443` (safer than public Funnel). Funnel was **not** re-enabled for SoulCore.
