## Implementation Details

### SoulCoreHealthSnapshot (new fields, all `init`, all nullable)

- `bool? SoulLoopEnabled` ← `soulLoop.enabled`
- `int? DriftActiveCount` ← `safety.drift.activeDriftCount`
- `bool? DriftSloExceeded` ← `safety.drift.sloExceeded`
- `int? DriftOldestMinutes` ← `safety.drift.oldestDriftMinutes`
- `long? SpendTokensIn` ← `safety.spend.totalTokensIn`
- `long? SpendTokensOut` ← `safety.spend.totalTokensOut`
- `decimal? SpendEstimatedCost` ← `safety.spend.estimatedCostUsd`
- `decimal? SpendMonthlyCap` ← `safety.spend.monthlyCapUsd`
- `bool? SpendCapExceeded` ← `safety.spend.capExceeded`

All use `init` accessors to match the existing snapshot pattern. All nullable so a Host that omits the new objects does not crash parsing.

### New DTOs (private, in SoulCoreHealthClient.cs)

- `SoulLoopDto { bool? Enabled }` (nullable because Host may omit `soulLoop`)
- `SafetyDto { DriftDto? Drift; SpendDto? Spend }`
- `DriftDto { int? ActiveDriftCount; bool? SloExceeded; int? OldestDriftMinutes }`
- `SpendDto { long? TotalTokensIn; long? TotalTokensOut; decimal? EstimatedCostUsd; decimal? MonthlyCapUsd; bool? CapExceeded }`

All properties use `[JsonPropertyName(...)]` matching the live JSON keys exactly.

### ApplySystemStatus (MainWindow.xaml.cs)

**SoulLoop** (`SystemSoulLoopBox`): replaced the `phase {n}` proxy with real `soulLoop.enabled`:
- `null` → "(not reported)", muted
- `true` → "enabled", `_okBrush` (green)
- `false` → "disabled", `_badBrush` (red)

**Charter lock** (`CharterLockBox`): replaced "locked (placeholder)" with "calibration" (warn brush). Rationale: all charter anchors use `is_locked=0` in the current Host build, so the charter is in calibration, not locked. The shell never rewrites anchors.

**Drift** (`CharterDriftBox`): shows `{activeDriftCount} active · SLO {exceeded|ok}`:
- both null → "(not reported)", muted
- SLO exceeded → `_badBrush`
- count > 0 but SLO ok → `_warnBrush`
- count 0 + SLO ok → `_okBrush`

**Spend** (`CharterSpendBox`): shows `{in}/{out} tokens · ${cost:0.0000} / ${cap:0}`:
- all null → "(not reported)", muted
- cap exceeded → `_badBrush`
- cost/cap > 0.8 (approaching cap) → `_warnBrush`
- otherwise → `_okBrush`

**Unreachable branch**: now also sets `CharterDriftBox` and `CharterSpendBox` to "unreachable" (`_badBrush`) for consistency (previously only `CharterLockBox` was set in that branch).
