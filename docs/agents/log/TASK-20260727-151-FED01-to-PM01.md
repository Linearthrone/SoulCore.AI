## Channel + settings keys

| Item | Value |
| --- | --- |
| Reply channel id | `victoria_replies` |
| Reply notification id | `15101` |
| Connected FGS channel (unchanged) | `victoria_connected` / id `15001` |
| Prefs store | plain `SharedPreferences` name `companion_prefs` |
| Enable key | `notif_enabled` (bool, default `true`) |
| Sound path key | `notif_sound_path` (string; empty = OS default notification sound) |
| Vibration key | `notif_vibration` (bool, default `true`) |

Custom sound files are imported into app-private `files/sounds/reply_custom` and exposed via `FileProvider` (`${applicationId}.fileprovider`) so the channel can play them. Changing sound or vibration deletes + recreates the channel (Android channel sound/vibration are immutable after create).

## Architecture

| Piece | Role |
| --- | --- |
| `AppForeground` | `ProcessLifecycleOwner` tracker — ding only when process stopped |
| `ReplyNotification` | Channel + post on `chat.done` + sound import + clear on open |
| `CompanionPrefs` / `NotificationPrefs` | Persist enable / sound path / vibration |
| `SettingsScreen` | Switches + pick custom sound / reset to system default |
| `CompanionApp` | Ensures both channels; installs frame collector |
| `MainActivity` | `singleTop`; handles tap; clears reply alert on resume (FGS notif untouched) |

Permissions: existing `POST_NOTIFICATIONS`; added `VIBRATE`.
