# TASK-094 — Add look_at keyword dispatch to HandleChatSendAsync

## Context

The `look_at` verb is the last Unreal body verb that is wired in the adapter/mapper
but never dispatched from the chat path. BED-088 (loco) and BED-092 (play_animation)
completed the same pattern for their verbs. This completes the full UE verb set:
speak, set_emotion, loco, play_animation, look_at.

The north-star plan (§3.1) specifies: "SoulCore sends commands: look_at_player,
play_animation, speak, set_emotion, set_gaze_target."

## Deliverable

Add a keyword-based look_at intent detection to `HandleChatSendAsync`, following
the exact same pattern as BED-088 (loco) and BED-092 (play_animation):

1. After the existing `PlayAnimationAsync` try/catch block, add a new independent
   try/catch block.
2. Create a `DetectLookIntent(string text)` method that:
   - Scans the ORIGINAL user chat text for look/gaze keywords
   - Keywords: "look at me", "look at player", "look", "gaze", "face me",
     "turn to me", "watch me", "see me"
   - Returns `true` if a look intent keyword is found, `false` otherwise
3. When look intent is detected, call `_unreal.LookAsync(null, cancellationToken)`
   (the payload is ignored by the mapper — it always sends `look_at_player`)
4. Log: `Unreal look intent dispatched: look_at_player (from chat text)`
5. Wrap in independent try/catch — look failure must never break chat flow

## Acceptance criteria

- [ ] `DetectLookIntent` method added to `ChatWebSocketHandler`
- [ ] `LookAsync` called when look keywords detected in user chat text
- [ ] Independent try/catch (look never breaks chat)
- [ ] Host log shows `Unreal look intent dispatched: look_at_player` when "look at me" in chat text
- [ ] All 62 existing tests pass
- [ ] Build: 0 errors, 0 warnings (excluding file-lock MSB302x)
- [ ] Report to `docs/agents/reports/TASK-20260723-094-BED01-to-PM01.md`

## Constraints

- Do NOT restart the Host
- Follow the exact same pattern as BED-088/092
- The look intent detection runs over the ORIGINAL user text
- Check multi-word phrases before single words ("look at me" before "look")
