## How to use (UI)

1. Start Host, then Presence shell (see Build / Run).
2. On **Presence**, emotion strip shows live `emotion.snapshot`.
3. Click **Correct…** → panel expands under the strip (not an overlay tray).
4. Adjust optional sliders; edit short note (default placeholder: “that wasn’t how I felt”).
5. **Save correction** → client sends:

```json
{
  "v": 1,
  "type": "emotion.correct",
  "id": "<guid>",
  "ts": "<iso>",
  "payload": {
    "valence": 0.2,
    "arousal": 0.4,
    "dominance": 0.5,
    "focus": 0.6,
    "note": "that wasn’t how I felt"
  }
}
```

1. Transcript gets a system line: `emotion.correct sent · v=… a=…`. Until BED-042, Host may return `error` / `frame.unsupported` — still counts as send attempted.
2. **Cancel** or click **Correct…** again to collapse.
