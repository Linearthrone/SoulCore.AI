# TASK-161: PreferHermes ↔ SoulCore tool-loop alignment (ISSUE-007/009/010)

## Problem

QA-145: with `PreferHermes=true`, chat uses Hermes (`provider=hermes`) but Hermes `tool_execution=server` runs **Hermes-native** tools. SoulCore `ITool` names (`mt4_status`, `browser_capture_tab`, `execute_trade`, …) are never dispatched → BED-144 `CallMcpToolAsync` path is bypassed. Gateway-down PreferHermes hangs 180s (ISSUE-009). API key mismatch SoulCore `.env` vs Hermes `API_SERVER_KEY` caused 401 until process override (ISSUE-010).

ISSUE-008 (computer_use capture TimeoutError) is **out of scope** for this ticket — file follow-up OPS if still needed after 007 is fixed; capture may work once SoulCore owns the tool call.

## Solution (required intent)

PreferHermes must mean: **Hermes is the LLM** for the turn, but **SoulCore owns tool dispatch** (same BED-126/128 loop as Ollama):

1. Chat path with PreferHermes builds `tools[]` from `IToolRegistry` and runs Host-side tool-loop (or equivalent) so model tool_calls map to SoulCore `ITool.ExecuteAsync`.
2. Tools with `*Backend=hermes` call `IHermesMcpInvoker.CallMcpToolAsync` (already Pass when PreferHermes=false).
3. Do **not** rely on Hermes server-side agent inventing `browser_snapshot` / native `computer_use` in place of SoulCore tool names.
4. PreferHermes + Hermes down: fail fast (`error` / `chat.done` with clear unavailable) within Host timeout — no 180s hang (ISSUE-009).
5. Document / align `SOULCORE_HERMES_API_KEY` with Hermes `API_SERVER_KEY` (ISSUE-010) — start script preflight or Example note; no secrets in git.

Leave `Hermes.Enabled=false` default in appsettings until QA-145 retest Pass (toggle via env for evidence).

## Acceptance criteria

1. PreferHermes=true: prompt forcing `mt4_status` → Host dispatches SoulCore `mt4_status` → `CallMcpToolAsync` (log evidence).
2. PreferHermes=true: `browser_capture_tab` / `desktop_screenshot` → SoulCore tool names in dispatch log (not Hermes-only `browser_snapshot` substituting away SoulCore tools).
3. PreferHermes=true + gateway stopped: chat turn completes ≤ Host timeout with unavailable/error — **no** hang.
4. PreferHermes=false: Ollama recall_memory regression still Pass.
5. ISSUE-007 / 009 Fixed; ISSUE-010 Fixed or documented with preflight; report evidence paths.
6. Unit/integration tests for PreferHermes tool-loop + gateway-down fail-fast.
