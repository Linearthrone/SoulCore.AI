## Root cause of earlier FAILs (for ops)

Headless **`UnrealEditor-Cmd -ExecutePythonScript`** runs on the game thread and **does not advance ticks**, so WP never releases **`ENavigationBuildLock::AsyncLoadLock (0x20)`**. Log signature:

```text
UNavigationSystemV1::Build Navigation NOT building because navigation build is locked (flags: 0x20).
```

**Working method:** `UnrealEditor.exe` + `-ExecCmds="py <no-space-path>"` so the editor ticks; script waits (~181 ticks) for `is_navigation_being_built_or_locked(world)==False`, then `RebuildNavigation`.

Do **not** use `-ExecutePythonScript` for nav bake (always exits when the script returns; tick callbacks never run to completion).
