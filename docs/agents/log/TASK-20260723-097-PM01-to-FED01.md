# TASK-097 — Wire desktop UI to real /health safety + soulLoop fields

## Context

BED-091 added `safety.drift` and `safety.spend` objects to the `/health` endpoint,
and the `soulLoop.enabled` field is already in `/health`. However, the desktop UI's
`SoulCoreHealthClient` does NOT parse these new fields, and `ApplySystemStatus` in
`MainWindow.xaml.cs` still uses placeholder values:
- `CharterLockBox.Text = "locked (placeholder)"`
- `CharterDriftBox` and `CharterSpendBox` exist in the null guard but are never set
- `SystemSoulLoopBox` shows `phase {n}` instead of the actual `soulLoop.enabled` value

The `/health` endpoint now returns:

```json
{
  "soulLoop": { "enabled": true },
  "safety": {
    "drift": { "activeDriftCount": 0, "sloExceeded": false, "oldestDriftMinutes": 0 },
    "spend": { "totalTokensIn": 62, "totalTokensOut": 88, "estimatedCostUsd": 0, "monthlyCapUsd": 30, "capExceeded": false }
  }
}
```

## Deliverable

### 1. Extend `SoulCoreHealthSnapshot` (SoulCoreHealthClient.cs)

Add new fields:
- `bool? SoulLoopEnabled` — from `soulLoop.enabled`
- `int? DriftActiveCount` — from `safety.drift.activeDriftCount`
- `bool? DriftSloExceeded` — from `safety.drift.sloExceeded`
- `int? DriftOldestMinutes` — from `safety.drift.oldestDriftMinutes`
- `long? SpendTokensIn` — from `safety.spend.totalTokensIn`
- `long? SpendTokensOut` — from `safety.spend.totalTokensOut`
- `decimal? SpendEstimatedCost` — from `safety.spend.estimatedCostUsd`
- `decimal? SpendMonthlyCap` — from `safety.spend.monthlyCapUsd`
- `bool? SpendCapExceeded` — from `safety.spend.capExceeded`

### 2. Extend `HealthDto` (private DTO in SoulCoreHealthClient.cs)

Add JSON-mapped properties for:
- `soulLoop` → `SoulLoopDto` with `enabled`
- `safety` → `SafetyDto` with `drift` and `spend` sub-objects

### 3. Update `ApplySystemStatus` (MainWindow.xaml.cs)

Replace placeholder values with real data:
- `SystemSoulLoopBox`: show `enabled` / `disabled` from `snap.SoulLoopEnabled`, green/red brush
- `CharterLockBox`: show `calibration` (since all anchors `is_locked=0`), not "locked (placeholder)"
- `CharterDriftBox`: show `{activeDriftCount} active, SLO {ok/exceeded}`, color-coded
- `CharterSpendBox`: show `{tokensIn}/{tokensOut} tokens, ${estimatedCostUsd} / ${monthlyCapUsd}`, color-coded

### 4. Update `ViewCharterAnchors_Click` (optional — if time allows)

Currently just toggles a panel visibility. If feasible, fetch the charter anchors from
the Host's `/health` or a new endpoint and display them. If not feasible in this task,
leave a TODO comment for a future ticket.
