## Verb gap: SoulCore vs HouseVictoriaBridge

SoulCore (`UnrealVerbFrame`): `{ "v", "type": "<verb>", "id", "ts", "payload" }`  

UE parser (`ParseWebSocketMessage`): verb only from `"type":"command"` → `payload.name`, or plain-text first token. Top-level `"type":"speak"` leaves `PrimaryVerb` empty → dropped.

| SoulCore verb | UE support |
|---|---|
| `set_emotion` | **Missing** |
| `speak` | Native `command`/`plain` — **envelope mismatch** |
| `play_animation` | Native — **envelope mismatch** |
| `loco` | **Missing** (nearest: `move_avatar_relative`, transform cmds) |
| `look` | **Missing** top-level (`autonomy`/`look_at_player`, BP `LookAt`) |
