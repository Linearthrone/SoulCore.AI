# TASK-104: Drift remediation — soft-block Unreal verbs when SLO exceeded

## Context

`DriftWatcher` is report-only. SoulLoop records a drift report **every tick**, so after `DriftSloMinutes` the SLO is always exceeded under normal load — that would wrongly soft-block forever. Fix recording first, then soft-block Unreal body verbs when SLO is truly exceeded. Chat text/inference stays allowed (unlike the spend gate).

## Acceptance criteria

### 1. Recording hygiene (`DriftWatcher.RecordDrift` emotion overload)
- Only enqueue a report when `score >= threshold` (i.e. `ExceedsThreshold`).
- Raise the fixed threshold from `0.5` to **`1.15`** so typical neutral/content states (`v≈0, a≈1` → score=1.0) do **not** enqueue; tense/extreme states still can (`sqrt(v²+a²) ≥ 1.15`).
- Update XML comments: no longer "report-only forever"; soft-block is caller's job when `SloExceeded`.

### 2. Soft-block in `ChatWebSocketHandler`
- After a successful chat reply (or when about to run Unreal side-effects), call `_driftWatcher.GetStatus()`.
- If `SloExceeded`:
  - Log **Warning**: drift SLO exceeded — Unreal verbs soft-blocked (include unacked count / oldest age).
  - **Skip** all Unreal side-effects for this chat: `SetEmotionAsync`, `SpeakAsync`, `LocoAsync`, `PlayAnimationAsync`, `LookAsync`.
  - Chat.done / episodic write / inference still proceed as today.
- If not exceeded: existing Unreal behavior unchanged.
- Inject `DriftWatcher` into the handler if not already (check constructor — may need to add it; it's already a DI singleton).

### 3. Optional ack path (minimal)
- Add HTTP `POST /health/drift/ack` that calls `AcknowledgeAll()` and returns `{ acked: N }` — so QA/Presence can clear the soft-block without Host restart. No auth beyond localhost bind (V1 already loopback-only).

### 4. Tests
- Update/add `DriftWatcherTests`: reports below threshold are not enqueued; score ≥ 1.15 enqueues; `SloExceeded` still works with aged reports.
- Build + Protocol.Tests pass.

### 5. Defaults
- Do **not** change live `DriftSloMinutes` (15). Production stays calm until extreme emotion + unacked age.

## QA trip recipe (document in report)
1. Restart Host with `SOULCORE_Safety__DriftSloMinutes=1`.
2. Send `emotion.correct` with valence=-0.9, arousal=1.0, dominance=0.5, focus=0.5 (score ≈ 1.35 ≥ 1.15).
3. Send `loop.tick` (or wait for SoulLoop) so a report is recorded.
4. Wait >60s without ack.
5. Send chat "please move forward" → expect **no** `Unreal loco intent dispatched` log; expect Warning soft-block instead.
6. `POST http://127.0.0.1:7700/health/drift/ack` → then loco works again.
7. Restore `DriftSloMinutes` default before leaving Host.
