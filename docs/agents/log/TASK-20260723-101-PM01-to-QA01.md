# TASK-101: Verify memory+charter context enrichment + E1-E9 regression

## Context

BED-100 wired episodic memory recall and charter identity anchors into the chat context preamble. The `ChatWebSocketHandler` now recalls 5 recent episodic memories and loads charter `identity` anchors before calling the inference client, combining them into a `[Identity] → [Memory] → [SoulCore emotion]` preamble. Additionally, PM applied a one-line fix to upgrade the SoulLoop episodic reflection log from Debug to Information level (in `SoulLoopScaffold.cs`).

These changes need a Host rebuild + recycle to take effect, then runtime verification.

## Acceptance criteria

### Step 1: Host recycle (OPS-style)
1. Stop the running Host process (find PID by checking `http://127.0.0.1:7700/health` or `Get-Process dotnet` / `Get-Process SoulCore.Host`).
2. Rebuild the solution: `dotnet build SoulCore/SoulCore.sln` — must succeed with 0 errors.
3. Start the Host: run `SoulCore/scripts/start-soulcore.ps1` (or `dotnet run --project SoulCore/SoulCore.Host`).
4. Verify `GET http://127.0.0.1:7700/health` returns status=ok with `soulLoop.enabled=true`.

### Step 2: Context preamble verification (E10 — new gate)
5. Send a chat.send frame with text "hello Victoria" to `ws://127.0.0.1:7700/ws`.
6. Confirm a chat.done frame is received with a non-empty reply.
7. Check the Host logs for evidence that the context preamble was built. Look for:
   - Memory recall (Debug-level log or evidence in the preamble)
   - Charter identity anchors loaded
   - The combined preamble passed to inference
   Note: The `BuildContextPreamble` method itself may not log at Information level. If no explicit log line exists, verify indirectly: the chat reply should be non-empty and the Host should NOT crash when memories/anchors are present.

### Step 3: SoulLoop reflection log visibility (E9b)
8. Wait for at least 2 SoulLoop ticks (120s+ with default 60s interval, or trigger a manual `loop.tick`).
9. Confirm the Host log now shows `SoulLoop episodic reflection written: [Reflection]...` at **Information** level (not Debug). This confirms the PM's log-level fix is live.

### Step 4: E1-E9 regression (no breakage)
10. **E1 speak**: Send "hello" → chat.done received, reply non-empty. (UE disconnected is OK — `soul=speak` not logged when UE down.)
11. **E3 loco**: Send "move forward 50" → Host log shows `Unreal loco intent dispatched: forward=50`.
12. **E7 play_animation**: Send "wave hello" → Host log shows `Unreal animation intent dispatched: anim=wave`.
13. **E8 look_at**: Send "look at me" → Host log shows `Unreal look intent dispatched: look_at_player`.
14. **E9 episodic reflection**: Confirm at least 1 row exists in `episodic_memories WHERE source='self'` with content starting `[Reflection]`.

### Step 5: Report
15. Write report to `docs/agents/reports/TASK-20260723-101-QA01-to-PM01.md` with:
   - Host recycle evidence (PID before/after, build output, /health response)
   - E10 context preamble: Pass/Fail + evidence
   - E9b reflection log: Pass/Fail + log line excerpt
   - E1/E3/E7/E8/E9 regression: Pass/Fail for each
   - Any observations or issues
