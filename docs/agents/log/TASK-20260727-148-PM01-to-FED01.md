# TASK-148: Wire SoulCore WS chat protocol in the Android companion

## Problem

Phone app must speak the same WS protocol as `House.ChatDesktop` (`chat.send` → `chat.delta` / `chat.done`).

## Do not

- Do not implement auth Keystore yet (FED-149) — accept token from settings string for now.
- Do not implement notifications (FED-150/151).
- Do not change Host protocol.

## Solution

1. OkHttp WebSocket to `{baseUrl}/ws` (default `ws://127.0.0.1:7700/ws`).
2. Send `chat.send` frames with text + sessionId.
3. Render streaming bubbles from `chat.delta`; finalize on `chat.done`.
4. Mirror frame shapes used by `House.ChatDesktop` / `SoulCore.Protocol`.

## Acceptance criteria

1. Against a running Host on loopback (emulator / USB reverse), one chat round-trip completes with assistant text.
2. Report includes exact WS URL, sample frames, and screenshot or log of deltas.
3. Reply: `docs/agents/reports/TASK-20260727-148-FED01-to-PM01.md`
