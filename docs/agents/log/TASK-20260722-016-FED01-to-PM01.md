## SoulCore WS frame shape (client contract)

Default: `ws://127.0.0.1:7700/ws` (Host may be HTTP-only today).

```json
{
  "v": 1,
  "type": "chat.send | chat.delta | chat.done | emotion.snapshot | presence.status | error | ping | pong",
  "id": "correlation-id",
  "ts": "2026-07-22T21:00:00.000Z",
  "payload": {}
}
```

| type | payload |
| --- | --- |
| `chat.send` | `{ "text", "sessionId?" }` |
| `chat.delta` / `chat.done` | `{ "text" }` |
| `emotion.snapshot` | `{ "valence", "arousal", "label", "note?" }` |
| `presence.status` | `{ "alive", "warm", "phase" }` |
| `error` | `{ "code", "message" }` |

Until BED exposes WS, client uses **HTTP health only** and keeps chat frames local.
