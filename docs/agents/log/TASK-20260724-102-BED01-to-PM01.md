## How QA trips the gate

1. Restart Host with a low token ceiling, e.g.:
   ```powershell
   $env:SOULCORE_Safety__MonthlyTokenCap = "50"
   # then start Host as usual
   ```
2. Send a few `chat.send` frames over WS (each successful reply records estimated tokens via chars/4).
3. Once cumulative in+out tokens ≥ 50, the next `chat.send` must return an `error` frame:
   - `code`: `chat.spend_cap`
   - `message`: `Monthly spend/token cap exceeded. Inference refused.`
   - correlated with the chat.send `id`
4. `/health` → `safety.spend.capExceeded` should be `true`.
5. Alternate path: set non-zero `InputTokenRatePer1K` / low `MonthlyCapUsd` so cost alone trips CapExceeded.

Defaults unchanged: rates `$0`, `MonthlyCapUsd=30`, `MonthlyTokenCap=0` (token gate off until set).
