## 2. Default roots

With `UseDefaultRoots=true` and empty configured lists (stock `appsettings.json`):

| Root | Mode | Resolution |
| --- | --- | --- |
| `%LOCALAPPDATA%/SoulCore/memory/` | read-only | env-expanded |
| `{SoulCorePackage}/scripts/qa-*/` | read/write | package root discovered by walking cwd/BaseDirectory for `SoulCore.sln` + `scripts/`; glob expanded to matching dirs |
| `{SoulCorePackage}/scratch/` | read/write | same package-root anchor |

`UseDefaultRoots=false` + empty lists → all three FS tools return `Success:false, "filesystem tools disabled"`.

Write defaults exclude memory (read-only). Explicit `FilesystemWriteRoots` must be used for custom write allow-lists.
