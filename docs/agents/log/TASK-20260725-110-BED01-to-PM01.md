# TASK-110: Backfill missing episodic embeddings

## Summary

Added `ListEpisodicsMissingEmbeddingsAsync` on `IMemoryStore` / `SqliteMemoryStore`, plus Host CLI mode `--backfill-embeddings` that exits after filling (no web host). Ran once against the live DB after briefly stopping Host to avoid SQLite locks.

## How to run

From `SoulCore/` (or any cwd; appsettings resolved from Host content root):

```powershell
dotnet run --project SoulCore.Host --no-launch-profile -- --backfill-embeddings
dotnet run --project SoulCore.Host --no-launch-profile -- --backfill-embeddings --limit 200
dotnet run --project SoulCore.Host --no-launch-profile -- --backfill-embeddings --db "C:\path\to\soulcore_memory.db" --limit 50
```

- Default DB: `Memory:DbPath` / `%LOCALAPPDATA%\SoulCore\memory\soulcore_memory.db` (same as `/health`)
- Default limit: **200**
- Model / Ollama URL: from `Inference` in `appsettings.json` (`nomic-embed-text`, `http://127.0.0.1:11434`)
- Prints: `scanned` / `filled` / `failed`; continues on single-row failures
- Idempotent: `LEFT JOIN` only lists rows without vectors; second run → `scanned=0`

**SQLite lock:** Prefer stopping Host while backfilling the live file. Concurrent Host + backfill can lock the DB.
