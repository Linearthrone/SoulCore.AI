# TASK-20260729-163 OPS-01 Completion Report

## Verdict: **Fail**

Hermes Agent **0.18.2** on this Windows machine **cannot** be configured for PreferHermes client-visible OpenAI `tool_calls`. The API server hardcodes `server_agent` / `tool_execution=server` / `split_runtime=false`. Completions responses never include `message.tool_calls`. **ISSUE-20260729-002 left Open** (not Fixed).

## Blocked reason (TT/PM Avenue)

Stock hermes-agent **0.18.2** is a **server-side agent gateway**: it runs Hermes-native (+ MCP) tools on the API host and returns only final `content`. PreferHermes architecture needs the opposite (LLM-only → client `tool_calls` → SoulCore ITools). That mode is explicitly documented as a **future** split-runtime ([#18715](https://github.com/NousResearch/hermes-agent/issues/18715)); it is **not** present in 0.18.2, and **no** `.env` / `config.yaml` key toggles it.

| C | Custom Host/proxy shim mapping Hermes events → OpenAI `tool_calls` | BED/OPS |
