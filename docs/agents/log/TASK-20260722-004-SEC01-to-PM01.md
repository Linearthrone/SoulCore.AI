## Phase 0 security plan

### 1. Secret storage policy (SoulCore V1)

| Secret class | Storage | Notes |
| --- | --- | --- |
| Cloud API tokens (A2E, HF, optional STT/TTS) | OS user env vars **or** .NET **User Secrets** (dev) / Windows Credential Manager / DPAPI-protected local file (prod always-on box) | Never in `appsettings.json`, `App.config`, or git |
| Local Hermes / Ollama “keys” | Env preferred; if required for OpenAI-compatible clients, generate random ≥32 chars locally — still not committed | Treat local keys as real secrets once LAN/Tailscale exists |
| App token (future remote companion) | Env + regenerate on rotate; ≥32 chars cryptographically random | V1: feature off |
| SQLite paths / non-secret knobs | SoulCore settings store (SQLite or `appsettings.json`) | Endpoints OK; connection strings with passwords → secret store |

#### Rules

1. Committed files may contain **keys names** and empty placeholders only (`""` / `${SOULCORE_A2E_TOKEN}`).
2. Provide `appsettings.Example.json` + `.env.example` — never real `.env`.
3. Host refuses to start cloud-dependent features if required secret missing (fail closed), except pure offline chat/memory path.
4. Logs: never write secret values (redact middleware).

### 2. Localhost bind policy

| Listener | V1 (Phase 0–5 soak) | Later (SEC gate) |
| --- | --- | --- |
| SoulCore Host HTTP/WS (chat, health, protocol) | **`127.0.0.1` only** | Tailscale interface **or** LAN only after app token + TLS/Tailscale; never raw public `0.0.0.0` without token |
| Unreal bridge client | Outbound to gaming PC; no inbound public | Same |
| House MCP / STT / Chatterbox | `127.0.0.1` | Same until SEC review |
| Remote companion / ERP-style multi-user | **Disabled / not built** | Never multi-user; remote = Tailscale + token + deny-by-default CORS |

#### Hard defaults for scaffold

- Bind address config default: `127.0.0.1`
- `ListenOnLan` / `0.0.0.0` requires explicit opt-in **and** non-empty app token ≥32 chars **and** SEC-01 sign-off ticket
- No `AllowAnyOrigin()` on any authenticated surface
