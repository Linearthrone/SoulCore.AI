# TASK-092 — Add play_animation keyword dispatch to HandleChatSendAsync

## Context

BED-088 successfully added loco intent detection to the chat path. The same pattern
should be extended for the `play_animation` verb. The `IUnrealVerbClient` interface
already has `PlayAnimationAsync(string animationName)` and `UeVerbWireMapper.MapPlayAnimation`
already maps to the UE `play_animation` frame. But nothing in `HandleChatSendAsync`
calls `PlayAnimationAsync`.

The north-star plan (§3.1) specifies: "SoulCore sends commands: look_at_player,
play_animation, speak, set_emotion, set_gaze_target."

## Deliverable

Add a keyword-based animation intent detection to `HandleChatSendAsync`, following
the exact pattern of BED-088's loco dispatch:

1. After the existing `LocoAsync` try/catch block, add a new independent try/catch block.
2. Create a `DetectAnimationIntent(string text)` method that:
   - Scans the ORIGINAL user chat text for animation keywords
   - Maps common animation names to UE animation names:
     - "wave" / "wave hello" / "wave goodbye" → `wave`
     - "nod" / "yes" → `nod`
     - "shake head" / "no" → `shake_head`
     - "bow" → `bow`
     - "clap" / "applaud" → `clap`
     - "dance" → `dance`
     - "laugh" / "giggle" → `laugh`
     - "thumbs up" → `thumbs_up`
     - "point" / "point at" → `point`
     - "jump" → `jump`
     - "sit" / "sit down" → `sit`
     - "stand" / "stand up" → `stand`
   - Returns the animation name string, or null if no animation keyword found
3. When an animation keyword is found, call `_unreal.PlayAnimationAsync(animationName, cancellationToken)`
4. Log: `Unreal animation intent dispatched: anim={animationName} (from chat text)`
5. Wrap in independent try/catch — animation failure must never break chat flow

## Acceptance criteria

- [ ] `DetectAnimationIntent` method added to `ChatWebSocketHandler`
- [ ] `PlayAnimationAsync` called when animation keywords detected in user chat text
- [ ] Independent try/catch (animation never breaks chat)
- [ ] Host log shows `Unreal animation intent dispatched: anim=wave` when "wave" is in chat text
- [ ] All 62 existing tests pass
- [ ] Build: 0 errors, 0 warnings (excluding file-lock MSB302x)
- [ ] Report to `docs/agents/reports/TASK-20260723-092-BED01-to-PM01.md`

## Constraints

- Do NOT restart the Host (OPS will handle that)
- Follow the exact same pattern as BED-088's loco dispatch
- Check multi-word phrases before single words (e.g., "wave goodbye" before "wave")
- The animation intent detection should run over the ORIGINAL user text, not the model reply
