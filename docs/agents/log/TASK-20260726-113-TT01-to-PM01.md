## Two live bugs worth their own small tickets

1. **`play_animation` never fires** — Host sends JSON `payload.args.name`;
   `HouseVictoriaBridgeServer` reads **PlainArgs only** → `success:false`.
   Same class as the old speak/BED-067 bug.
2. **`look` is a no-op** — Host sends `autonomy` with `args.command`;
   `ParseAutonomyCommand` takes `payload.name` (literal `"autonomy"`), which
   `ReceiveAutonomyCommand` doesn't match.
